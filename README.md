# Controle de Turma em PHP

Exemplo simples desenvolvido para a atividade do curso técnico de Desenvolvimento de Sistemas da ETEC, demonstrando o uso de **estruturas de repetição** e **funções** em PHP.

## Sobre o projeto

A aplicação simula uma tela de controle de turma: o usuário informa quantos alunos a turma possui e o sistema gera uma tabela com os dados de cada aluno.

## Conceitos aplicados

- **Estrutura de repetição `for`**
- **Estrutura de repetição `while`**
- **Função com retorno** 
- **Função sem retorno (void)** .
- **`$_POST`**
